# ralr 文档索引

ralr 是一个简单的基于寄存器的虚拟机（VM）及其汇编器，使用 Rust 编写。

## 文档列表

- [安装指南](install.md) — 如何编译、安装和卸载 ralr
- [关键字参考](keywords.md) — 表达式语法、运算符表、代码块、寄存器和值类型说明
- [汇编语言指南](assembly-guide.md) — 如何编写 `.ralr` 汇编源文件，包含表达式和旧式语法的完整示例

## 语言特性概览

- **表达式语法**：`$reg = expr;` — 支持 24 种运算符，标准优先级，括号分组
- **代码块**：`{ ... }` — 嵌套指令序列，为控制流结构奠定基础
- **5 个通用寄存器**：`$a1`–`$a5`
- **10 种值类型**：`None`、`I32`、`I128`、`U8`、`U32`、`U128`、`F32`、`F64`、`Bool`、`String`
- **I/O 操作**：`io write`/`writeln` 输出，`io read`/`readln` 输入
- **控制流**：`if`/`else if`/`else` 条件分支
- **旧式关键字指令**：`add`/`sub`/`mul`/`div`、`_print`/`_println`（向后兼容）
