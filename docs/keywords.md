# 关键字参考

## 表达式赋值

表达式是 ralr 推荐的主要编程方式：

```
$寄存器 = 表达式;
```

表达式支持完整的运算符优先级和括号分组。

### 运算符优先级（由低到高）

| 优先级 | 运算符 | 结合性 | 说明 |
|--------|--------|--------|------|
| 2 | `\|\|` | 左 | 逻辑或 |
| 3 | `&&` | 左 | 逻辑与 |
| 4 | `\|` | 左 | 按位或 |
| 5 | `^` | 左 | 按位异或 |
| 6 | `&` | 左 | 按位与 |
| 7 | `==` `!=` | 左 | 相等 / 不等 |
| 8 | `<` `>` `<=` `>=` | 左 | 小于 / 大于 / 小于等于 / 大于等于 |
| 9 | `<<` `>>` | 左 | 左移 / 右移 |
| 10 | `+` `-` | 左 | 加法 / 减法 |
| 11 | `*` `/` `%` | 左 | 乘法 / 除法 / 取余 |
| 12 | `-` `!` `~` | — | 一元取反 / 逻辑非 / 按位非 |

> **注意**：运算符与操作数之间必须有空格分隔，例如 `1 + 2`（正确），`1+2`（错误）。

### 运算符分类

**算术运算符**：`+` `-` `*` `/` `%`

作用于整数（I32/I128/U8/U32/U128）和浮点数（F32/F64）。`%` 为取余运算。操作数类型必须相同。

**比较运算符**：`==` `!=` `<` `>` `<=` `>=`

作用于数值类型和字符串，返回 `Bool`（`true` 或 `false`）。操作数类型必须相同。

**逻辑运算符**：`&&` `||` `!`

仅作用于 `Bool` 类型。`&&` 和 `||` 为非短路求值（两侧表达式均会计算）。

**位运算符**：`&` `|` `^` `~`

仅作用于整数类型（I32/I128/U8/U32/U128）。

**移位运算符**：`<<` `>>`

仅作用于整数类型，采用环绕移位（`wrapping_shl`/`wrapping_shr`），移位量被掩码处理。

**一元运算符**：`-`（取反）、`!`（逻辑非）、`~`（按位非）

- `-`：作用于有符号整数和浮点数。若操作数为无符号字面量，汇编器会在编译时自动折叠为有符号负数（如 `-128` → `I32(-128)`）。
- `!`：仅作用于 `Bool`。
- `~`：仅作用于整数类型。

### 括号

使用 `(` `)` 对子表达式进行分组，覆盖默认优先级：

```
$a1 = (1 + 2) * 3;    // 9，而非 7
```

## 条件分支（if / else if / else）

使用 `if` 根据条件执行代码块：

```
if 条件表达式 {
    指令;
}
```

### 基本语法

```
if $a1 > 0 {
    _println "positive";
}
```

条件表达式必须求值为 `Bool` 类型。若条件为 `true` 则执行紧随的代码块，否则跳过。

### else 分支

```
if $a1 > 0 {
    _println "positive";
} else {
    _println "zero or negative";
}
```

### else if 链

```
if $a1 > 0 {
    _println "positive";
} else if $a1 == 0 {
    _println "zero";
} else {
    _println "negative";
}
```

`else if` 可多次链式使用，末尾的 `else` 可选。条件表达式中可使用任意运算符（比较、逻辑、算术等）：

```
if $a1 > 0 && $a2 < 100 {
    $a3 = 1;
} else if $a1 == 0 || $a2 == 0 {
    $a3 = 0;
}
```

`if` 语句可任意嵌套，`if` 语句末尾不需要分号。

## 代码块

使用 `{` `}` 将多条指令组织为一个代码块。代码块可以嵌套，是后续 `if`/`while`/`fn` 等控制流结构的基础。

```
{
    指令1;
    指令2;
    {
        指令3;   // 嵌套块
    }
    指令4;
}
```

块内指令共享外层寄存器状态。空块 `{ }` 是合法的。

## 指令（旧式关键字语法）

以下旧式关键字仍然可用，用于向后兼容。

### 算术指令

格式：`指令 操作数1 操作数2 $目标寄存器`

| 指令 | 说明 | 示例 |
|------|------|------|
| `add` | 加法 | `add 1 2 $a1` |
| `sub` | 减法 | `sub $a1 1 $a1` |
| `mul` | 乘法 | `mul $a1 3 $a1` |
| `div` | 除法 | `div $a1 2 $a2` |

操作数1 和 操作数2 可以是立即数（字面量）或寄存器。目标寄存器必须是一个寄存器。

### 打印指令

接受一个操作数（立即数或寄存器），将其输出到标准输出：

| 指令 | 说明 | 示例 |
|------|------|------|
| `_println` | 打印并换行 | `_println $a1` / `_println "text"` |
| `_print` | 打印（不换行） | `_print "hello"` / `_print "\n"` |

## 寄存器

ralr 提供 5 个通用寄存器，在汇编代码中以 `$` 前缀引用：

| 寄存器 | 写法 |
|--------|------|
| A1 | `$a1` |
| A2 | `$a2` |
| A3 | `$a3` |
| A4 | `$a4` |
| A5 | `$a5` |

程序启动时，所有寄存器的初始值均为 `None`。

## 值类型

汇编器会根据字面量自动推断值类型，解析优先级如下：

| 类型 | 示例 | 说明 |
|------|------|------|
| `Bool` | `true`, `false` | 布尔值 |
| `U8` | `0`–`255` 范围内的整数 | 8 位无符号整数 |
| `U32` | 超出 `u8` 范围但在 `u32` 范围内的整数 | 32 位无符号整数 |
| `U128` | 超出 `u32` 范围但在 `u128` 范围内的整数 | 128 位无符号整数 |
| `I32` | 负数在 `i32` 范围内 | 32 位有符号整数 |
| `I128` | 负数在 `i128` 范围内 | 128 位有符号整数 |
| `F32` | 包含小数点的数字 | 32 位浮点数 |
| `F64` | 包含小数点的数字（默认） | 64 位浮点数 |
| `String` | 用双引号包裹的字符串，如 `"hello"`，支持所有 ASCII 转义字符 | 字符串 |

### 转义字符

字符串字面量支持以下转义序列：

| 写法 | 含义 |
|------|------|
| `\n` | 换行 |
| `\t` | 制表符 |
| `\\` | 反斜杠 `\` |
| `\"` | 双引号 `"` |
| `\r` | 回车 |
| `\'` | 单引号 `'` |
| `\a` | 响铃（Bell, 0x07） |
| `\b` | 退格（Backspace, 0x08） |
| `\f` | 换页（Form Feed, 0x0C） |
| `\v` | 垂直制表（Vertical Tab, 0x0B） |
| `\e` | 转义字符（Escape, 0x1B） |
| `\0` | 空字符 |
| `\xNN` | 十六进制字节（如 `\x20` = 空格） |
| `\u{NNNN}` | Unicode 码点（如 `\u{4e2d}` = 中） |

示例：`"hello\nworld"` 输出为 `hello` 和 `world` 各占一行。

> **注意**：字符串必须用双引号 `"` 包裹（如 `"hello"`）。未加引号的单词不再被识别为字符串，会触发解析错误。类型推断顺序意味着 `255` 会被解析为 `U8`，而 `256` 会被解析为 `U32`。

## 语法分隔符

- **分号 `;`**：指令分隔符。多条指令可以写在同一行，用分号分隔。每条指令必须以分号结尾。
- **大括号 `{` `}`**：代码块分隔符。用于将多条指令组织为一个嵌套块。

## 注释

| 语法 | 说明 |
|------|------|
| `//` | 行注释。`//` 之后到行尾的所有内容均被忽略。 |
| `/* … */` | 块注释。`/*` 和 `*/` 之间的所有内容均被忽略，支持跨行。 |

字符串字面量内部的注释分隔符被视为普通字符，不会被识别为注释。
