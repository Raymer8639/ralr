# 汇编语言指南

## 源文件格式

`.ralr` 文件是 ralr 的汇编源文件，使用纯文本格式。每条指令以分号 `;` 结尾，支持在一行内编写多条指令。

## 表达式（推荐语法）

表达式是 ralr 推荐的主要编程方式，支持完整的运算符优先级和括号分组：

```
$寄存器 = 表达式;
```

### 基本运算

```
$a1 = 10 + 5;
$a2 = ($a1 - 3) * 2;
$a3 = $a2 > 20;       // 比较运算，返回 Bool
$a4 = 255 & 15;       // 位运算
$a5 = 1 << 4;         // 移位运算
$a6 = -(10);          // 一元取反
$a7 = !false;         // 逻辑非
```

### 运算符一览

| 分类 | 运算符 | 示例 |
|------|--------|------|
| 算术 | `+` `-` `*` `/` `%` | `$a1 = 10 + 5;` |
| 比较 | `==` `!=` `<` `>` `<=` `>=` | `$a1 = 5 < 10;` |
| 逻辑 | `&&` `\|\|` `!` | `$a1 = true && false;` |
| 位运算 | `&` `\|` `^` `~` | `$a1 = 240 & 15;` |
| 移位 | `<<` `>>` | `$a1 = 1 << 4;` |
| 一元 | `-` `!` `~` | `$a1 = -5;` |

> **注意**：运算符与操作数之间必须有空格，如 `1 + 2`（正确），`1+2`（错误）。

### 运算符优先级

高优先级运算符先计算。使用括号 `( )` 可以覆盖默认优先级：

```
$a1 = 1 + 2 * 3;       // 7  （* 优先于 +）
$a1 = (1 + 2) * 3;     // 9  （括号覆盖）
$a1 = 1 + 2 < 3 * 4;   // true（算术优先于比较）
```

完整优先级表（由低到高）：`||` → `&&` → `|` → `^` → `&` → `==` `!=` → `<` `>` `<=` `>=` → `<<` `>>` → `+` `-` → `*` `/` `%` → 一元 `-` `!` `~`

## 代码块

使用 `{` `}` 将多条指令组织为一个代码块，支持嵌套：

```
{
    $a1 = 10;
    _println $a1;
    {
        $a2 = $a1 + 5;
        _println $a2;
    }
}
```

块内指令共享外层寄存器状态。代码块是 `if`/`while`/`fn` 等后续控制流结构的基础。

## 打印输出

使用 `_println`（打印并换行）和 `_print`（打印不换行）输出值：

```
_println $a1;
_println "hello world";
_print "no newline";
_print "\n";
```

字符串必须用双引号 `"` 包裹，支持转义字符（`\n`、`\t`、`\\`、`\"` 等）。

## 旧式关键字语法（向后兼容）

以下关键字式指令仍然可用：

### 示例：基本运算

```
add 1 2 $a1;
sub $a1 1 $a1;
mul $a1 2 $a1;
div $a1 2 $a1;
```

上述代码的计算过程：`((1 + 2) - 1) × 2 ÷ 2 = 2`，最终结果存入 `$a1`。

等价的表达式写法：

```
$a1 = 1 + 2;
$a1 = $a1 - 1;
$a1 = $a1 * 2;
$a1 = $a1 / 2;
```

## 编译为二进制

使用 `ralr-asm` 将 `.ralr` 源文件编译为 `.abin` 二进制文件：

```bash
ralr-asm input.ralr -o program.abin
```

## 运行二进制

使用 `ralr` 运行 `.abin` 二进制文件：

```bash
ralr program.abin
```

## 完整工作流

```bash
# 1. 编写汇编源文件
cat > test.ralr << 'EOF'
$a1 = (10 + 5) * 2 - 3;
_println $a1;
$a2 = $a1 > 20;
_println $a2;
_println "done";
EOF

# 2. 编译
ralr-asm test.ralr -o test.abin

# 3. 运行
ralr test.abin
```
